① 底部功能区压缩：通栏功能条 → 右下角紧凑簇（电源键 Ø12 + LED + 前置 USB3 竖排），左下角改进风格栅；CPU 散热限高 30→25mm（N100 6W 余量仍 2.4 倍）；盘位起点 z 42→36 → 整机高 180→170。

③ 散热开孔：两侧下部冲压百叶（主板区进风，每侧 4 条 100×4，下倾 15° 防尘）+ 底板 Ø8 冲孔阵列（内贴防尘网）+ 前脸左下格栅。
④ 机框-盘位视觉收窄：盘面开口仍 112×27（物理下限 = 3.5" 盘宽 101.6 + 导轨），每层增加 150×30.5 冲压凹槽面板，单侧视觉留白 35→16mm，零成本钣金工艺。
⑤ 勘误：v1.0 BOM 合计误写 ¥795.6，实为 ¥789.1；v1.1 重新核算为 ¥787.3（散热/脚垫/前面板小板降价，钣金因百叶+冲孔工艺微涨）。

§2内部结构剖面（侧剖 · 风道）

N100 ITX 卧式底置（散热限高 25）；4 盘位螺锁导轨在其上方；背板立于盘尾；后置 92mm 风扇在尾部风腔。冷风三路：底板冲孔 + 两侧百叶 + 前脸左下格栅 → 掠过主板 → 尾腔 → 风扇排出。硬盘靠壳体传导 + 盘间缝被动散热。

深度链（不变）：前脸 3 + 盘 147(含余量 9) + 背板 12 + 风腔/风扇 25 + 走线 10 + 后壁 3 ≈ 202。高度链 v1.1：脚 2.5 + 底板 1.2 + 铜柱 5 + 板 1.6 + 散热 25 = 35.3 → 盘位 z36 起 + 4×32.5 = 166 + 顶隙 4 = 170（v1.0 为 180）。

§8下一步

  1. 主板到货实测：采购 2-3 款 N100 4×SATA ITX 板（畅网/倍控/CWWK），确认 SATA 口位置、散热器限高 25mm 可行性、I/O 挡扳对位 → 回填 Z1L-S01 开孔坐标。
  2. FreeCAD 钣金建模：按 v1.1 图纸出 Z1L-S01/S02/S03 展开图 + DXF（直接发激光切割厂），百叶/冲孔阵列在展开图上定位。
  3. 手板验证：激光切割 1 套钣金 + 3D 打印前脸功能件，验证装配/缝隙/百叶强度。
  4. 热验证（v1.1 重点）：2.5mm 脚垫 + 侧百叶方案，4 盘满载 iozone + iperf3；盘温 ≤45°C / CPU ≤75°C / 噪音 ≤28dB@1m；不达标则换 4mm 脚垫备选孔位。
  5. 背板打样：嘉立创 4 口被动背板（MOS 软启动版），4 盘同时上电浪涌测试（12V 5A 带载）。
  6. 软件：nas-panel 增加 Z1 Lite 机型 profile；前面板按键/LED 接主板 F_PANEL 针脚（零 MCU 成本）。
