# NAS Web 管理面板实现计划

> **For Hermes:** 使用 subagent-driven-development 按 task 实现。

**Goal:** 为 NAS 项目构建一个轻量级 Web 管理面板，用 Go 编写，编译成单个二进制文件，通过 systemd 运行，端口 8090。

**Architecture:** Go 单二进制，内嵌 HTML/CSS/JS 前端（go:embed），后端用 net/http 提供 REST API。通过调用 systemctl、smbpasswd、htpasswd 等系统命令管理服务和用户。JWT 认证，从 .env 读取 NAS_PASS。

**Tech Stack:** Go + go:embed + 原生 net/http + JWT + 内嵌前端（Alpine.js + Tailwind CSS CDN）

---

## 功能模块

### 1. 仪表盘 (Dashboard)
- 系统信息：主机名、IP、CPU/内存/磁盘使用率、运行时间
- 服务状态一览：8 个服务的 active/inactive 状态 + 端口
- 快速操作：重启全部服务、停止全部服务

### 2. 服务管理 (Services)
- 列出所有 NAS 服务（smbd, nmbd, nfs-kernel-server, vsftpd, rclone-webdav, filebrowser, minio, fail2ban）
- 每个服务：启动/停止/重启按钮、状态显示、端口显示
- 服务日志查看（journalctl 最近 50 行）

### 3. 用户管理 (Users)
- 列出系统用户（通过 /etc/passwd 和 pdbedit -L）
- 添加用户（调用 add-user.sh）
- 删除用户（调用 remove-user.sh）
- 修改密码（smbpasswd + chpasswd）

### 4. 存储信息 (Storage)
- 磁盘使用率（df -h）
- 目录大小（du -sh /data/*）
- Samba 共享列表（testparm -s）
- NFS 导出列表（exportfs -v）
- SMART 状态（smartctl -H）

### 5. 防火墙 (Firewall)
- UFW 状态（ufw status numbered）
- 当前规则列表
- 快速操作：允许/拒绝端口

## API 设计

| Method | Path | 功能 |
|--------|------|------|
| POST | /api/login | 登录，返回 JWT |
| GET | /api/dashboard | 系统概览 |
| GET | /api/services | 服务列表+状态 |
| POST | /api/services/{name}/start | 启动服务 |
| POST | /api/services/{name}/stop | 停止服务 |
| POST | /api/services/{name}/restart | 重启服务 |
| GET | /api/services/{name}/logs | 服务日志 |
| GET | /api/users | 用户列表 |
| POST | /api/users | 添加用户 |
| DELETE | /api/users/{name} | 删除用户 |
| PUT | /api/users/{name}/password | 修改密码 |
| GET | /api/storage | 存储信息 |
| GET | /api/storage/smart | SMART 状态 |
| GET | /api/firewall | 防火墙规则 |
| POST | /api/firewall/allow | 允许端口 |
| POST | /api/firewall/deny | 拒绝端口 |

## 前端设计

- 浅色主题（符合用户偏好）
- 左侧导航栏：仪表盘 / 服务 / 用户 / 存储 / 防火墙
- 顶部：NAS 名称 + 登出按钮
- Alpine.js 做响应式数据绑定，无需构建工具
- Tailwind CSS CDN 做样式，大字体高对比度
