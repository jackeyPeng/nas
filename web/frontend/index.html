备份说明

                

                    
备份内容：

                    
    
                        
  • 系统配置：smb.conf / exports / nfs.conf / vsftpd.conf / jail.local 等
    • 
                        
  • systemd 服务文件：rclone-webdav / filebrowser / minio / nas-panel
    • 
                        
  • NAS 项目配置：.env / configs/ 目录
    • 
                        
  • 用户数据：Samba 用户数据库 / FTP 白名单 / 系统用户列表
    • 
                        
  • crontab 任务（监控告警 + 定期备份）
    • 
                        
  • 系统状态快照（磁盘/服务状态/挂载点/UFW）
    • 
                    

                    
自动备份：

                    
    
                        
  • 升级前自动备份（运行 setup.sh 时触发）
    • 
                        
  • 每周日凌晨 3 点定期备份（cron）
    • 
                        
  • 保留最近 5 个备份，自动清理旧的
    • 
                    

                    

                        ⚠️ 恢复操作会停止所有服务、覆盖当前配置后重启。请确认备份时间正确。
