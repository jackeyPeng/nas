4 × 3.5"前置免工具热插拔托架，兼容 2.5" HDD/SSD
≈ 2.1 kg整机空重（铝壳 + 木底座）
< 25 dB满载噪音（后置 92mm PWM ≤2000RPM）
60 W外置 DC 12V/5A，4 盘启动峰值余量 25%
¥1182量产 BOM（1000 台批价，不含硬盘/税运）
⚠ 尺寸修訂说明（v0.3 更新） — 原 HARDWARE_SPEC §6.2 方案一为 185×165×155mm（≈4.7L）。经结构核算：3.5" 硬盘本体长 147mm，加托架(12) + 背板(14) + 后置风道(25) + 壁厚(8)，深度物理下限 ≈ 206mm；155mm 深度只能放 2.5" 盘。另经查证（2026-10-15）：市面 N150 NAS ODM 板（CWWK CW-M2 / M6 / 各 6×SATA 款）全部为 170×170mm Mini-ITX，无 ≤150×140 紧凑现货板。故分两档执行：
① 原型版（Phase 0/1，本次 FreeCAD 建模对象）：装 ITX 现货板，主板卧式底置 → 186(W) × 184(H) × 210(D) ≈ 7.2L（与群晖 DS423+ 7.4L 相当）；
② 量产愿景版（本页 §1-§4 图纸所示）：待自研/定制紧凑板（≤150×140）侧置板仓 → 179 × 162 × 217 ≈ 6.3L。
两档共用：托架/背板/风道理念/CMF/前脸设计语言。HARDWARE_SPEC.md §1、§6.2 已同步修订。

设计语言延续规格书已定的「留白」方向：暖白喷砂阳极氧化铝一体壳 + 胡桃木底座 + 炭灰托架。像家居摆件不像 IT 设备：正面只有四条盘位缝、一根暖白灯条和一枚电源键；进风格栅藏在木底座下方；螺丝全部不外露（底部硅胶垫下 + 背板内锁）。磁吸前装饰面板可换色（白 / 木纹 / 墨绿），是量产后的配件收入点。

§2内部结构剖面（A–A 侧剖 · 风道示意）

布局：前置 4 盘位竖列 → 定制 SATA 背板 → 右侧竖装主板仓（紧凑 ODM 板 ≤150×140）→ 后置 92mm 排风。冷风从胡桃木底座下方进入，走主板仓与盘仓夹缝，由后扇抽出；硬盘区靠壳体传导 + 托架间通风缝被动散热（降噪）。

剖面尺寸链合计 ≈ 217mm（深度）。盘仓与板仓之间留 14mm 夹缝风道；主板 I/O 通过延伸支架对位后窗开孔。

§3装配爆炸图（前 → 后装配顺序）

装配顺序自内向外：壳体 → 主板组件 → 背板 → 盘仓框架 → 托架 → 风扇/后窗 → 磁吸面板 → 木底座（最后从底部锁 6 颗螺丝，外壳无可见螺丝）。

§8原型版（ITX 现货板 · FreeCAD 建模对象）

Phase 0/1 手板按此建模：186(W) × 184(H) × 210(D) ≈ 7.2L。与量产愿景版的差异只在主板布置（卧式底置 vs 侧置板仓），前脸/托架/背板/CMF 完全一致，手板验证的装配与风道结论可直接迁移。

§9验证清单 / 下一步

  1. 结构建模：FreeCAD/Fusion360 按本图纸建 1:1 模型 → 导出 STL（对应 PURCHASE_LIST §八的 3D 打印采购项）。
  2. Phase 0 手板：PLA 打印壳 + 托架，装入 ODM N150 板（先确认板型尺寸 ≤150×140 或改用加深原型壳），验证装配公差与走线。
  3. 热验证：4 盘满载 + iperf3 + 转码压力，测 CPU/盘温与噪音；目标盘温 ≤45°C、噪音 ≤25dB@1m。
  4. 背板打样：嘉立创 4 层小批量（5 片起），验证热插拔浪涌与 LED 链路。
  5. 软件对接：MCU 温控板暴露串口/I2C → 接入 nas-panel 的 hardware/monitor 模块（GET /api/hardware/profile 已预留平台识别）。
