# Z1 Lite 基础款 4-Bay NAS · v1.1（2026-11-04）

紧凑型、降本、无底座的 4 盘位（3.5"）家用 NAS 产品设计，面向厂家投产。与 `../z1-4bay/`（Z1 标准版）共用软件栈（nas-panel / Debian 13）与设计语言，硬件全面降本。

## 核心参数

- **外形 182(W) × 170(H) × 202(D) ≈ 6.25L**，硅胶脚 2.5mm 直贴（无底座）
- 4×3.5" 前置盘位，**螺锁导轨 + 注塑压条 + 凹槽面板**（非热插拔托架），节距 32.5
- N100 ITX ODM 板（4×SATA / 1×2.5GbE / DDR4 8G / NVMe 128G）**卧式底置**，散热限高 25mm，无 WiFi
- 壳体 **SPCC 1.0 钣金 + 喷粉**（RAL9010 暖白 / RAL9005 哑黑），ABS 注塑前脸功能件
- 散热：侧百叶×2 + 底板冲孔 + 前脸格栅进风 → 后置 92mm PWM 排风；盘区被动散热
- 外置 DC 12V/5A 60W（CCC/PSE 认证）

## 渲染图核验记录（v1.1）

管线：文生图候选（wan2.2-t2i-flash）→ 视觉核验（盘位数/底座/材质）→ **图生图**（wanx2.1-imageedit，基图 R2 预签名 URL）锁定合格机身做改形/换景/改色：
1. `studio-white.png` = v1.0 合格基图 imageedit 改形（低机身+功能簇右下角+侧百叶）→ 核验：**4 盘位✓ 底部收窄✓ 侧百叶✓**
2. `hero-lifestyle.png` = 同基图 imageedit 换家居场景 → 核验：**4 盘位✓ 无底座✓ 紧凑比例✓**
3. `studio-black.png` = imageedit 改黑失败（模型保色不改），改用 studio-white 程序化暗色调映射 → 核验：**哑光炭黑✓ 4 盘位✓ 百叶可见✓**（已知瑕疵：电源键圈偏亮）
4. `detail-tray.png` 为 v1.0 概念示意（盘位数不符规格），图纸中已标注
