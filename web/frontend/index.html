推荐方案

                        

                            将磁盘配置为新的存储空间

                            自动完成格式化、挂载、开机自启、权限、Samba 共享
                        

                        
                    


                    
                    

                        
请选择存储方式（点击选择）：


                        

                            
                            

                                
📦 容量优先

                                
所有磁盘合并为一个大目录

                                

                                    磁盘1 + 磁盘2 → 合并为一个存储空间

                                    总容量 = 各磁盘容量之和
                                

                                
⚠️ 任一磁盘故障，数据全部丢失

                            


                            
                            

                                
🛡️ 安全优先

                                
两块磁盘互为镜像备份

                                

                                    磁盘1 = 磁盘2 → 一个镜像存储空间

                                    容量 = 单块磁盘大小
                                

                                
✓ 一块盘坏了，数据不丢

                            


                            
                            

                                
📁 独立模式

                                
每块磁盘独立一个目录

                                

                                    磁盘1 → 存储空间1，磁盘2 → 存储空间2 ...
                                

                                
各盘独立，坏一块不影响其他

                            

                        


                        
                        

                            ⚠️ 重要提醒
                            

                                以上操作将擦除选中磁盘上的所有数据。

                                如果这些磁盘上有重要数据，请先备份！

备份恢复


                
创建备份

                
手动创建一份当前 NAS 配置的快照（系统配置 + 服务文件 + 用户数据 + crontab）

                

                
备份列表

                
                

                    
                        
备份时间大小文件名操作

                    
                    
                        
                        

                            暂无备份
                        

                    
                


                
备份说明

                

                    
备份内容：

                    
    
                        
  • 系统配置：smb.conf / exports / nfs.conf / vsftpd.conf / jail.local 等
    • 
                        
  • systemd 服务文件：rclone-webdav / filebrowser / minio / nas-panel
    • 
                        
  • NAS 项目配置：.env / configs/ 目录
    • 
                        
  • 用户数据：Samba 用户数据库 / FTP 白名单 / 系统用户列表
    • 
                        
  • crontab 任务（监控告警 + 定期备份）
    • 
                        
  • 系统状态快照（磁盘/服务状态/挂载点/UFW）
    • 
                    

                    
自动备份：

                    
    
                        
  • 升级前自动备份（运行 setup.sh 时触发）
    • 
                        
  • 每周日凌晨 3 点定期备份（cron）
    • 
                        
  • 保留最近 5 个备份，自动清理旧的
    • 
                    

                    

                        ⚠️ 恢复操作会停止所有服务、覆盖当前配置后重启。请确认备份时间正确。
