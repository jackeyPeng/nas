## 核心参数

- **外形 182(W) × 180(H) × 202(D) ≈ 6.6L**，硅胶脚直贴（无底座）
- 4×3.5" 前置盘位，**螺锁导轨 + 注塑压条**（非热插拔托架，最大降本项之一），节距 32.5
- N100 ITX ODM 板（4×SATA / 1×2.5GbE / DDR4 8G / NVMe 128G）**卧式底置**，无 WiFi
- 壳体 **SPCC 1.0 钣金 + 喷粉**（RAL9010 暖白 / RAL9005 哑黑），ABS 注塑前脸
- 后置 92mm PWM 排风；底部+侧面进风；盘区被动散热
- 外置 DC 12V/5A 60W（CCC/PSE 认证）

## 渲染图核验记录

AI 文生图无法稳定控制盘位数量（12 张候选仅 1 张 4 盘位合格），最终采用两段式：
1. 文生图（wan2.2-t2i-flash，n=4×3 批）→ 视觉核验筛出 `studio-white.png`（4 盘位✓ 无底座✓）
2. **图生图**（wanx2.1-imageedit description_edit，基图上传 R2 预签名 URL）→ `hero-lifestyle.png`（家居场景，4 盘位✓）、`studio-black.png`（哑黑 CMF，4 盘位✓）
3. `detail-tray.png` 为概念示意（盘位数不符规格），图纸中已标注
