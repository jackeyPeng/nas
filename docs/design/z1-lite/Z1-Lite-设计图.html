§2内部结构剖面（侧剖 · 风道）

N100 ITX 主板卧式底置；4 盘位螺锁导轨在其上方；背板立于盘尾；后置 92mm 风扇在主板上方的尾部风腔。冷风：底部/侧面进风 → 掠过主板 → 尾部风腔 → 风扇排出。硬盘靠壳体传导 + 盘间缝被动散热。

深度链：前脸 3 + 盘 147(含前后余量 9) + 背板 12 + 尾部风腔/风扇 25 + 走线余量 10 + 后壁 3 ≈ 200 → 取 202。高度链：脚 5 + 底板 1.2 + 柱 6 + 板 1.6 + 散热 30 + 盘仓 130 + 顶 5 ≈ 180。

§8下一步

  1. 主板到货实测：采购 2-3 款 N100 4×SATA ITX 板（畅网/倍控/CWWK），确认 SATA 口位置、散热器限高（≤30mm）、I/O 挡扳对位 → 回填 Z1L-S01 开孔坐标。
  2. FreeCAD 钣金建模：按本图纸出 Z1L-S01/S02/S03 展开图 + DXF（可直接发激光切割厂），复用 z1-4bay 的 build_model.py 骨架。
  3. 手板验证：激光切割 1 套钣金 + 3D 打印前面板（M01 开模前先用打印件验证装配/缝隙）。
  4. 背板打样：嘉立创 4 口被动背板（MOS 软启动版），验证 4 盘同时上电浪涌（12V 5A 适配器带载测试）。
  5. 热验证：4 盘满载 iozone + iperf3，盘温 ≤45°C / 噪音 ≤28dB@1m 达标后锁 BOM。
  6. 软件：nas-panel 增加 Z1 Lite 机型 profile（hardware 模块已预留平台识别）；前面板按键/LED 若无 MCU 则接主板 F_PANEL 针脚（零成本方案）。
