产品概述

NAS 家用存储系统是一套基于 Debian 13 (trixie) 的轻量级 NAS 解决方案，全部使用原生 systemd 服务，不依赖 Docker 容器化，追求稳定、高性能、易维护。

核心特点

🔧 全原生服务

Samba/NFS/FTP/WebDAV/S3 全部原生 systemd 服务，无容器层故障点，最少抽象层 = 最稳定

📦 Go 单二进制面板

Web 管理面板编译成单个二进制文件，内嵌前端，内存占用 <3MB，跟 FileBrowser 一样轻量

💾 统一存储

一份文件六种协议访问：SMB / NFS / FTP / WebDAV / Web UI / S3 API，数据不再被对象格式隔离

📡 实时监控告警

磁盘/内存/CPU/网络流量/SMART/服务状态实时监控，支持钉钉/Telegram/Bark/邮件四通道告警

安全与运维

安全体系

🛡️ 防火墙

UFW 默认 deny，仅开放必要端口。Web 面板可在线管理端口规则

🔒 入侵防护

Fail2ban SSH/FTP 暴力破解防护，自动封禁异常 IP

🔐 密码管理

密码通过 .env 文件管理，不硬编码。12 位长度强制校验

📋 权限白名单

sudoers 精确限定 Web 面板可执行的 root 命令，最小权限原则

🔄 自动更新

unattended-upgrades 自动安装安全补丁

💾 配置备份

升级前自动备份，每周定期备份，一键恢复，保留最近 5 个

一键部署

$ git clone https://gitee.com/gitdogcat/nas.git ~/soft/nas $ cp ~/soft/nas/.env.example ~/soft/nas/.env $ # 编辑 .env 填入密码（至少12位） $ sudo bash ~/soft/nas/scripts/setup.sh [1/10] 安装基础软件包... ✓ [2/10] 创建数据目录结构... ✓ [3/10] 配置 Samba... ✓ [4/10] 配置 NFS... ✓ [5/10] 配置 FTP... ✓ [6/10] 配置 WebDAV... ✓ [7/10] 安装 FileBrowser... ✓ [8/10] 配置 S3 对象存储... ✓ [9/10] 配置防火墙和安全... ✓ [10/10] 安装 Web 管理面板... ✓

模块化架构

Web 面板采用模块化设计，10 个功能模块各自独立，共用 common/ 包的认证、JSON、sudo 工具函数。添加新功能只需新建模块目录、实现 RegisterRoutes、在 main.go 加一行注册。
